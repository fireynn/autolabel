Autolabel Studio — авторазметка датасета для Darknet YOLOv4-tiny
==================================================================

БЫСТРЫЙ СТАРТ
  1. Распакуйте архив в папку без русских букв в пути (например C:\AutolabelStudio).
  2. Дважды кликните START.bat.
     Первый запуск (20–60 минут) сам: поставит Python 3.11 (если нужно), окружение .venv,
     PyTorch под вашу видеокарту NVIDIA (или для процессора), пакеты, модели, ярлык на рабочем столе.
     Прокси не используется — прямое подключение.
  3. Дальше START.bat или ярлык «Autolabel Studio» сразу открывают приложение.
  Прервалась установка — запустите START.bat ещё раз, скачанное не потеряется.

ПРИЛОЖЕНИЕ (вкладки)
  1. Классы и образцы — классы, описания, образцы refs/<класс>/ и мусор refs/_reject/
  2. Разметка         — видео/фото/папки, пресеты, живое превью, «Следующее видео», «Остановить»
  3. Чистка           — сетка вырезок: Del удалить, 1..9 класс, R в мусор, S в образцы, F кадр,
                        P похожие, V проверить через VLM, A принять ответы VLM, Ctrl+Z отмена
  4. Кадры            — редактор рамок (рисовать, двигать, менять класс)
  5. Статистика       — проверки датасета, train/valid, cfg, корзина
  6. Обучение         — dataset.zip и инструкция для Colab
  7. Сеть и модели    — прокси (по умолчанию выключен), скачивание моделей, проверка видеокарты
  8. VLM-судья        — локально (Ollama) или через API (ProxyAPI, VseGPT, AITunnel, RouterAI...),
                        список моделей с размерами и ценами

ДРУГИЕ ИНСТРУМЕНТЫ
  CUT_VIDEO.bat     — нарезка видео на кадры (перетащите видео на файл)
  TEST_CAMERA.bat   — проверка обученной модели на веб-камере/видео
                      (положите в папку model: .weights + .cfg + .names  или  best.pt)
  colab\train_yolov4_tiny.ipynb — обучение YOLOv4-tiny в Google Colab
                      (colab.research.google.com → Файл → Загрузить блокнот → T4 GPU)

ПАРАМЕТРЫ START.bat (из консоли в этой папке)
  START.bat --preset best      модели для точного пресета
  START.bat --cpu              PyTorch без видеокарты
  START.bat --reinstall-torch  переустановить PyTorch (после обновления драйвера)

ФАЙЛЫ
  autolabel_app.py  — приложение            autolabel.py     — разметка (можно из консоли)
  vlm.py            — VLM-судья             check_dataset.py — проверка датасета из консоли
  video_to_frames.py— нарезка видео         webcam_test.py   — тест модели
  install.py        — установщик            classes.yaml     — классы (пример: 8 дорожных знаков)

Удалить всё: удалите эту папку и ярлык на рабочем столе.
