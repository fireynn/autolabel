Autolabel Studio — авторазметка датасета для Darknet YOLOv4-tiny

ЗАПУСК: двойной клик по START.bat

Первый запуск (20–60 минут, зависит от интернета) сам:
  - поставит Python 3.11, если подходящего нет
  - создаст окружение .venv в этой папке (систему не трогает)
  - поставит PyTorch под вашу видеокарту NVIDIA (или для процессора)
  - поставит остальные пакеты и скачает модели в папку models
  - создаст ярлык «Autolabel Studio» на рабочем столе
Прокси не используется — прямое подключение к интернету.

Дальше START.bat сразу открывает приложение.

Параметры (запуск из консоли в этой папке):
  START.bat --preset best     скачать модели для точного пресета
  START.bat --cpu             PyTorch без видеокарты
  START.bat --reinstall-torch переустановить PyTorch (например, после обновления драйвера)

Если установка прервалась — просто запустите START.bat ещё раз, скачанное не потеряется.
Удалить всё: удалите эту папку (и ярлык на рабочем столе).
