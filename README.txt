Autolabel Studio — авторазметка датасета для Darknet YOLOv4-tiny

ЗАПУСК: двойной клик по START.bat

Первый запуск (20–60 минут, зависит от интернета) сам:
  - поставит Python 3.11, если подходящего нет
  - создаст окружение .venv в этой папке (систему не трогает)
  - поставит PyTorch под вашу видеокарту NVIDIA (или для процессора)
  - поставит остальные пакеты и скачает модели в папку models
  - создаст ярлык «Autolabel Studio» на рабочем столе
Прокси не используется — прямое подключение к интернету.

Дальше START.bat сразу открывает приложение.

Параметры (запуск из консоли в этой папке):
  START.bat --preset best     скачать модели для точного пресета
  START.bat --cpu             PyTorch без видеокарты
  START.bat --reinstall-torch переустановить PyTorch (например, после обновления драйвера)

Если установка прервалась — просто запустите START.bat ещё раз, скачанное не потеряется.
Удалить всё: удалите эту папку (и ярлык на рабочем столе).

ТЕСТ ОБУЧЕННОЙ МОДЕЛИ НА ВЕБ-КАМЕРЕ: TEST_CAMERA.bat
  Положите в папку model (рядом с файлами) модель:
    YOLOv4 (Darknet): yolov4-tiny-custom_best.weights + yolov4-tiny-custom.cfg + obj.names
    или PyTorch (YOLOv8/11 и т.п.): best.pt
  Конкретный файл:  TEST_CAMERA.bat --weights C:\путь\best.pt
  Клавиши: Q — выход, Пробел — пауза, S — снимок, R — запись видео, +/- — порог, F — весь экран
  Другая камера:   TEST_CAMERA.bat --cam 1
  На видео:        TEST_CAMERA.bat --source C:\путь\video.mp4

НАРЕЗКА ВИДЕО НА КАДРЫ: CUT_VIDEO.bat
  Перетащите видео или папку с видео на CUT_VIDEO.bat — спросит, сколько кадров в секунду брать.
  Кадры появятся в папке frames. Из консоли больше настроек:
    CUT_VIDEO.bat video.mp4 --every 10          каждый 10-й кадр
    CUT_VIDEO.bat video.mp4 --count 300         300 кадров равномерно
    CUT_VIDEO.bat video.mp4 --start 0:30 --end 2:15 --fps 5 --dedup 3 --blur 60

VLM-СУДЬЯ (вкладка «8. VLM-судья»)
  Визуальная языковая модель проверяет сомнительные рамки при разметке и выделенные вырезки в «Чистке».
  Локально: установите Ollama (кнопка «Установить Ollama»), выберите модель (для 6 ГБ видеопамяти —
            qwen3-vl:4b) и нажмите «Скачать модель».
  Через API: выберите сервис (ProxyAPI, VseGPT, AITunnel, Polza.ai, provod.ai, OpenRouter, OpenAI),
            вставьте ключ из личного кабинета, выберите модель с картинками («Список моделей»).
  В «Чистке»: выделите вырезки → V (проверить) → оранжевые = VLM не согласна → A (принять) или вручную.
